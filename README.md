# 🧮 Modern Calculator with History (Python Tkinter)

A sleek, dark-themed desktop calculator built using Python and Tkinter. It handles standard arithmetic operations and records a live scrolling history of all past calculations during your session.

---

## ✨ Features
- **Modern Dark UI:** Clean obsidian/dark theme design with high-contrast accent buttons.
- **Live Calculation History:** Keeps track of previous calculations so you can easily review past inputs and outputs.
- **Error Handling:** Built-in try-except blocks to gracefully catch invalid mathematical syntax.
- **Lightweight:** Built entirely using Python's standard `tkinter` library—zero external dependencies required!

---

## 🚀 How to Run

1. Make sure you have **Python** installed on your system.
2. Clone or download this repository.
3. Open your terminal or VS Code in the project directory.
4. Run the application using the following command:

```bash
python calculator.py
